Inside the evidence layer

The tools behind Rehearse

A tech stack is the languages, libraries and services used to build a product. Rehearse uses plain Markdown to keep acceptance evidence beside a specification, then runs its examples through the SpecScore CLI.

Pre-v1

Rehearse is in active development. The scenario commands below run in the SpecScore CLI today; the format is not yet a stable release.

The product

Markdown that executes

Scenarios are Markdown files with Given, When and Then sections and executable Bash, SQL or HTTP steps. Reusable **Use:** checks keep shared outcomes in one place. The SpecScore CLI runs these commands and generates a readable acceptance-criteria summary, so a reviewer can trace a promise to evidence.

This website

A small static front door

The public site is hand-authored HTML and CSS, published from this repository's landing/ directory through Cloudflare Pages. It explains the sign-in example without requiring a browser app or account.
